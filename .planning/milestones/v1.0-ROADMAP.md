# Plano Certo - Development Roadmap (Archived v1.0)

O redesenho do Plano Certo foi executado em 4 fases sequenciais concluídas com sucesso.

## Fase 1: Fundação & Design System (UI/UX) [x]
- **Objetivo**: Estabelecer os tokens de design do CSS Vanilla premium, glassmorphism e micro-animações.
- **Entregáveis**:
  - Atualização dos estilos globais (`src/react.css` e arquivos CSS associados).
  - Componentes de UI básicos com estilização refinada (botões, inputs, cards e modais).
- **Verificação**: Teste visual estático de páginas com a nova aparência.

## Fase 2: Schema de Banco Supabase & Webhooks [x]
- **Objetivo**: Atualizar o banco de dados no Supabase para suportar Instagram, o cache do Google Places e tabelas de mensagens unificadas.
- **Entregáveis**:
  - Script SQL atualizado (`supabase/schema.sql`).
  - Atualização da Edge Function do webhook para suportar mensagens e status do WhatsApp e Instagram.
- **Verificação**: Rodar `npm run supabase:check` e simular webhooks de entrada.

## Fase 3: RAG & Automação dos Agentes [x]
- **Objetivo**: Ligar o agente autônomo com base de conhecimento (ANS e catálogo) e criar a fila de aprovação outbound.
- **Entregáveis**:
  - Implementação das consultas de similaridade vetorial (embeddings ANS).
  - Rotina de aprovação de templates/outbound no n8n.
  - Testes do webhook integrando o agente automático nas respostas inbound.
- **Verificação**: Enviar mensagens inbound mock e validar se a IA gera a resposta com citações da base de dados.

## Fase 4: Integração de Frontend & Caixa de Entrada [x]
- **Objetivo**: Conectar o frontend do React 19 aos endpoints reais do Supabase (substituindo `src/services/` mocks).
- **Entregáveis**:
  - Integração do Inbox em tempo real (Supabase Realtime).
  - Painel do Google Places com ativação de leads e cache.
  - Tela da Fila de Aprovação de Mensagens Outbound.
- **Verificação**: End-to-end teste com envio e recebimento de mensagens reais no painel pelo corretor.
